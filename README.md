# Homebrew Tap for Nomos

Official [Homebrew](https://brew.sh) tap for [**Nomos**](https://github.com/mgantlett/nomos) - the deterministic execution substrate and 42-gate polyglot AST verification layer between coding agents and Git (Apache 2.0).

## Install

```bash
brew install --cask mgantlett/tap/nomos
```

## Upgrade

```bash
brew upgrade --cask nomos
```

## Uninstall

```bash
brew uninstall --cask nomos
```
